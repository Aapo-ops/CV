1.	Yhteenveto ja Esittely

Käyttäjä voi Varata luokkia ja poistaa niitä varauksesta.
1.1.	Projektin kuvaus

•	Käyttäjä voi Varata luokkia ja poistaa niitä varauksesta. Varaukset on tallennetta tietokantaan ja kalenterin mukaan sitten lähtevät automaattisesti pois kun varauksen päivämäärä on mennyt.

1.2. Projektin tavoitteet
Projekti on toimiva 19.11 mennessä.
1.3. Sidosryhmät
•	Koulu, opettaja ja tiimi

1.4.Vaatimukset.
•	Varaukset lähtevät automaatisesti. käyttäjä ei voi varata luokkaa joka on jo varattu. sivusto on helppokäyttöinen ja mukavan näköinen.
